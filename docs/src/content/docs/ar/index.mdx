## ملف واحد لكل صفحة، وعنوان URL بكل لغة

<CardGrid>
<Card title="مع نظام i18n المدمج في Astro" icon="document">
يتطلب كل عنوان URL مترجم نسخة خاصة به من الصفحة.

<FileTree>

- src/pages/
  - a-propos.astro
  - en/
    - about.astro

</FileTree>

</Card>
<Card title="مع astro-localized-routes" icon="approve-check">
صفحة واحدة، ومسار لكل لغة في إعداداتك.

<FileTree>

- src/pages/
  - about.astro

</FileTree>

</Card>
</CardGrid>

```js title="astro.config.mjs"
localizedRoutes({
  locales: ["fr", "en"],
  defaultLocale: "fr",
  routes: {
    "/about": { fr: "/a-propos", en: "/about" },
    "/blog/[slug]": { fr: "/journal/[slug]", en: "/blog/[slug]" },
  },
});
```

| الصفحة              | `fr` (الافتراضية) | `en`              |
| ------------------- | ----------------- | ----------------- |
| `index.astro`       | `/`               | `/en`             |
| `about.astro`       | `/a-propos`       | `/en/about`       |
| `blog/[slug].astro` | `/journal/[slug]` | `/en/blog/[slug]` |
