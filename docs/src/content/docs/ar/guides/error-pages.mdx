## ما الذي يُولَّد

عندما يحتوي مشروعك على صفحة `404.astro` أو `500.astro`، تحصل كل لغة على نسختها الخاصة:

<FileTree>

- src/pages/
  - 404.astro
  - 500.astro

</FileTree>

| الصفحة      | `fr` (الافتراضية) | `en`      |
| ----------- | ----------------- | --------- |
| `404.astro` | `/404`            | `/en/404` |
| `500.astro` | `/500`            | `/en/500` |

لا يمكن ترجمة مسار صفحة الخطأ: فهو دائمًا `/{locale}/404`، لأن الوسيط والاستضافات الثابتة تحتاج إلى العثور عليها هناك. ويُحتفظ دائمًا بصفحات الخطأ الجذرية، وتُستخدم للأخطاء الواقعة خارج أي بادئة لغة.

## كيف تُعرض الصفحة الصحيحة

يعرض Astro دائمًا صفحة الخطأ الجذرية. وعندما يبدأ المسار المطلوب بلغة، يعرض وسيط التكامل نسخة تلك اللغة بدلًا منها، مع رمز الحالة الصحيح. على سبيل المثال، يعرض `/en/missing` الصفحة `/en/404` مع رمز الحالة 404، وتُرجع الدالة [`getLocale`](/ar/guides/current-locale/) القيمة `en` فيها.

زيارة نسخة مترجمة مباشرةً، مثل `/en/404`، تُرجع أيضًا رمز الحالة 404.

## المخرجات الثابتة ومخرجات الخادم

- **مخرجات الخادم:** تُصيَّر صفحات الخطأ المترجمة دائمًا عند الطلب، ليتمكن الوسيط من اختيار الصفحة الصحيحة.
- **المخرجات الثابتة:** تقدّم استضافتك صفحة الخطأ مباشرةً، وهي التي تقرر أيّها يُعرض. راجع توثيق استضافتك لمعرفة كيف تختار صفحة 404.
- **المخرجات الثابتة مع محوّل:** أضف `export const prerender = false` إلى صفحة الخطأ إن أردت أن يتولاها الوسيط.

## اختيار صفحات الخطأ

يحدد الخيار [`errorPages`](/ar/reference/configuration/#errorpages) صفحات الخطأ التي تُترجم. أبقِ صفحة 404 وحدها، أو اضبطه على `[]` لتعطيل هذه الميزة:

```js title="astro.config.mjs"
localizedRoutes({
  // ...
  errorPages: [404],
});
```

## استخدام صفحات خطأ مترجمة خاصة بك

إذا كان مشروعك يحتوي بالفعل على صفحة مثل `src/pages/en/404.astro`، فإنها تتعارض مع النسخة المولَّدة. اضبط `errorPages: []` لاستخدام صفحاتك الخاصة.

## التكاملات الأخرى

كما هو الحال مع صفحات الخطأ الجذرية، لا يُقصد إدراج النسخ المترجمة. فلا تتلقاها التكاملات الأخرى ضمن مساراتها وصفحاتها، لذا لا يُدرج `@astrojs/sitemap` الصفحة `/en/404`. راجع [خريطة الموقع والتكاملات الأخرى](/ar/guides/other-integrations/).
