## The problem

Astro's built-in i18n gives every page the same path in every locale. Translating the path itself (`/a-propos` in French, `/en/about` in English) means duplicating the page file for each locale.

## The idea

Write each page once in `src/pages`, then map it to a path for each locale in your Astro config.
