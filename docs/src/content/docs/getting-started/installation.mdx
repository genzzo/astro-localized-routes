---
title: Installation
description: Add astro-localized-routes to an Astro 6 or 7 project.
---

import { Tabs, TabItem } from "@astrojs/starlight/components";

Install the package with your package manager:

<Tabs syncKey="pkg">
  <TabItem label="npm">

    ```sh
    npm install astro-localized-routes
    ```

  </TabItem>
  <TabItem label="pnpm">

    ```sh
    pnpm add astro-localized-routes
    ```

  </TabItem>
  <TabItem label="Yarn">

    ```sh
    yarn add astro-localized-routes
    ```

  </TabItem>
  <TabItem label="Bun">

    ```sh
    bun add astro-localized-routes
    ```

  </TabItem>
</Tabs>

Then add it to your Astro config. The [quick start](/getting-started/quick-start/) walks you through a complete setup.

## Requirements

- Astro 6 or 7
