## Add the integration

Configure `locales`, `defaultLocale` and `routes` in `astro.config.mjs`.

## Create your pages

Write pages in `src/pages` as usual, with language-neutral file names.

## Check the routes

Run `astro dev` and visit each localized path.

## Use the locale in a page

Read the current locale with `getLocale` and set `<html lang>`.
