## Un fichier par page, une URL dans chaque langue

<CardGrid>
<Card title="Avec l'i18n intégrée d'Astro" icon="document">
Une URL traduite nécessite sa propre copie de la page.

<FileTree>

- src/pages/
  - a-propos.astro
  - en/
    - about.astro

</FileTree>

</Card>
<Card title="Avec astro-localized-routes" icon="approve-check">
Une seule page, et un chemin par langue dans votre configuration.

<FileTree>

- src/pages/
  - about.astro

</FileTree>

</Card>
</CardGrid>

```js title="astro.config.mjs"
localizedRoutes({
  locales: ["fr", "en"],
  defaultLocale: "fr",
  routes: {
    "/about": { fr: "/a-propos", en: "/about" },
    "/blog/[slug]": { fr: "/journal/[slug]", en: "/blog/[slug]" },
  },
});
```

| Page                | `fr` (par défaut) | `en`              |
| ------------------- | ----------------- | ----------------- |
| `index.astro`       | `/`               | `/en`             |
| `about.astro`       | `/a-propos`       | `/en/about`       |
| `blog/[slug].astro` | `/journal/[slug]` | `/en/blog/[slug]` |

## Fonctionnalités

<CardGrid stagger>
  <Card title="URL traduites" icon="translate">
    Donnez à chaque page, routes dynamiques comprises, son propre chemin dans chaque langue.
  </Card>
  <Card title="Fonctions typées" icon="seti:typescript">
    `getLocale` et `getAlternates` sont typées à partir de votre configuration.
  </Card>
  <Card title="Pages d'erreur localisées" icon="warning">
    Chaque langue a ses propres pages 404 et 500.
  </Card>
  <Card title="Compatible avec les autres intégrations" icon="puzzle">
    Les sitemaps et les autres intégrations ne voient que les routes localisées.
  </Card>
</CardGrid>
